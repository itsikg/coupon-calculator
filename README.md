# מחשבון תלושים

PWA פשוטה לחישוב תשלום באמצעות תלושי 10 ו־7 נקודות.

## העלאה ל-GitHub Pages

1. צור Repository חדש ב-GitHub.
2. העלה את כל הקבצים שבתיקייה הזו לשורש ה-Repository.
3. בצע Commit.
4. עבור אל Settings → Pages.
5. תחת Build and deployment בחר:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
6. שמור.

כתובת האתר תהיה בדרך כלל:

https://USERNAME.github.io/REPOSITORY/

## התקנה בטלפון

### iPhone
פתח את האתר ב-Safari → Share → Add to Home Screen.

### Android
פתח ב-Chrome → Install app / Add to Home screen.

האפליקציה עובדת גם Offline לאחר טעינה ראשונה.
